# ProjectManagementWeb

業務システム開発を想定した案件管理システムの Web 画面です。  
HTML / CSS を使用して構築しており、案件一覧、ステータス表示、検索フォーム、登録フォームなど、管理画面で一般的に利用される構成を再現しています。

---

## ■ 画面構成

### ● 案件一覧
- 案件ID  
- 案件名  
- 担当者  
- ステータス（受付中 / 進行中 / 完了）  
- 開始日  
- テーブル形式で表示

### ● 案件検索（簡易）
- 案件名検索（テキスト入力）
- ステータス選択（プルダウン）
- フロントエンドのみ（送信処理なし）

### ● 案件登録フォーム
- 案件名入力
- 担当者入力
- ステータス選択
- 概要入力
- フロントエンドのみ（送信処理なし）

---

## ■ 使用技術

- HTML5  
- CSS3  
- レイアウト・テーブル・フォームの基本実装  
- 開発環境：Visual Studio Code（VSCode）

---

```
ProjectManagementWeb/
```
